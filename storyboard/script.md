# 劇本：最後一班車之後

> 定稿 v3，已實作。調性參考《OPUS：靈魂之橋》：末日但不悲情，故事的重點是送別。遺物、場景、3D 模型都沿用現有的，這份只改敘事、新增錄音和時間線。

## 一句話

2085 年，外送機器人 DLV-06 在西門町醒來，身上有一封沒送到的信，還有一個損毀的音訊緩衝區。它走過的地方會突然響起三十一年前的聲音：救護車、警報、有人在跑、有人在喊一個名字，可是街上什麼都沒有。把這些聲音和遺物排回時間線之後，玩家會發現一件機器人自己不知道的事：那一晚，兩個人都去找了對方。等它終於走到收件人的家，她已經在今年春天離開了。它能做的，是把那一晚他喊她名字的聲音，放給她聽。

## 核心設計

| | 遺物 | 錄音 |
|---|---|---|
| 形式 | 看得到、撿起來 | 聽得到、看不到來源 |
| 觸發 | 自己操控開過去 | 經過錄音點自動觸發（巡遊也會） |
| 呈現 | 回憶小卡 | 環境音壓低、空間音效播放、底部出現轉錄字幕 |
| 進度 | 隨時可撿 | 依幕開放，後面的幕還沒開時不會響 |

**不用填答案，也不幫玩家下結論。** 遊戲只負責把東西給玩家，串起來是玩家自己的事：

1. **線索只寫事實**：卡片和字幕只寫看到、聽到的東西，例如時間、名字、一句話、刷卡紀錄。不寫「所以他趕上了」這類結論，也不會因為撿到別的東西就改寫內容。
2. **時間線只負責排順序**：找到的遺物和錄音會自動掛到時間軸上的位置，還缺的位置顯示 `??:??` 和大概的區域。時間線上不畫連線，也不加註解。
3. **系統訊息也只給數據**：機器人的系統訊息只報數字和狀態，例如停機位置、跟目的地的距離，不替玩家解釋。
4. **卡片不顯示擁有者**：下面每張卡標的擁有者只是寫給設計看的，遊戲裡不會出現。誰的東西，要玩家自己認出來。

### 為什麼會有聲音？（世界觀解釋）

西門町的外送機器人共用一張「街區音訊網」，原本是用來聽行人和車輛、避免碰撞。斷電前最後一次同步時，整個街區好幾年的聲音都被寫進 DLV-06 的緩衝區，但資料是碎的。只有回到錄音的原地點，用位置指紋重新對齊，那一段才解得開。

所以錄音只出現在西門町。**草原村沒有任何錄音**，那裡唯一的聲音是真的：音樂盒。

## 序章：日常

醒來後，機器人會照「今日排程」做一些外送機器人每天都在做的小事。這段沒有目標、沒有提示箭頭、不會失敗，玩家照自己的步調逛就好。

**呈現方式**
- 畫面角落有一張小小的「今日排程」，項目完成就打勾，旁邊跳出一行系統訊息。不強迫玩家去做。
- 這段期間，錄音點全部沉默，雷達也還不出現。遺物可以撿，但時間線還沒開啟，撿到的卡片先收在圖鑑裡。
- 多數項目在自動巡遊時也會發生，就算玩家放著不管，機器人自己也會慢慢把日常過完。

### 今日排程

| 項目 | 怎麼完成 | 系統訊息 |
|---|---|---|
| **晨間自檢** | 醒來後自動進行：輪子轉一下、貨箱開關一次、喇叭嗶一聲 | `輪組 OK・貨箱 OK・喇叭 OK・外觀：苔蘚覆蓋 38%` |
| **曬太陽充電** | 停在沒有屋頂遮蔽的空地上，靜止幾秒（陰天、雨天不算） | `太陽能板展開……電量 12% → 64%` `今天天氣很好。` |
| **問候顧客** | 靠近一隻貓或狗（第一次問候土狗時，牠會變成同伴，見「同伴」一節） | `偵測到顧客（四足）` `您好！今天想吃點什麼？` 貓跑掉後：`顧客滿意度：無法評估` |
| **清空配送路徑** | 開進鴿群，讓牠們飛起來 | `配送路徑已淨空（34 隻）` |
| **遵守交通號誌** | 經過彩虹斑馬線時，機器人會自己停下來等兩秒 | `號誌：無訊號・推定為綠燈` `通過。` |
| **清潔鏡頭** | 遇到第一場雨（自然下雨或按 R） | `鏡頭清潔中……` `謝謝雨。` |
| **巡邏外送路線** | 照舊路線走完峨眉街 → 漢中街 → 武昌街 | `巡邏完成・沿途店家：營業中 0／歇業 47` |

這些系統訊息就是機器人的個性：一板一眼、有點天真，還在用三十一年前的禮貌對待一座空城。

### 觸發主線

**完成任 4 項，或者醒來滿 6 分鐘**（以先到者為準），主線就開始。觸發時機挑在下一次「排程項目完成」的訊息之後，讓它看起來像日常自己接下去：

```
> 今日排程：完成
> 載入下一筆排程……
> 錯誤：前一筆訂單尚未結案（2054-04-30 23:12 受理）       （紅）
>   寄件人：███████
>   收件人：███████
>   目的地：███████
> 讀取訂單紀錄……失敗
> 改為讀取音訊緩衝區……
> 音訊緩衝區：14 段損毀・需在原地點重新對齊
```

接著時間線開啟、雷達出現，第一幕的錄音點開始有反應。

### 主線開始後，日常還在

日常項目不會消失，變成整趟旅程中隨時可能發生的小事，沒有進度、也不計分：

- 每次遇到貓狗還是會說「您好！今天想吃點什麼？」。
- 經過彩虹斑馬線還是會停下來，等那個不會變的燈。

（躲雨、看夕陽這兩項先不做：場景目前沒有日夜變化，騎樓也還沒有可以導航過去的位置。）

這些時刻刻意不跟主線扯上關係，讓這座城在謎團之外也有它自己的生活。

## 錄音一覽

**只有錄音是立體聲**：現實世界的聲音維持單聲道，錄音一響起，聲音才在左右展開。雨、人群鋪滿兩側，鏟子、撞擊聲落在左邊或右邊，移動的聲音（救護車、跑步）依畫面方向移動。R11 他從右邊跑來，R12 她從左邊跑回來。

每段錄音的流程：音樂和環境音在 1 秒內壓到 20%，畫面下方先顯示 `偵測到異常音訊……`，接著換成 `▶ 2052-09-14 01:50` 這樣的時間，開始播放；播完後顯示 `已存入時間線`，音量再慢慢恢復。

字幕是機器人的「轉錄」：聽不清楚的地方用 `……` 或 `（雜訊）` 帶過。

**R1｜2049-07-22 14:10｜西寧南路與成都路口（往河堤的方向）**
- 聲音：遠方的防汛警報，長鳴、升降三次；附近有人聊天，有人笑。
- 字幕：
  - （警報）
  - 「又來了。」
  - 「今年第幾次？」
  - 「第三吧。走啦，電影要開始了。」

**R2｜2052-09-14 01:50｜峨眉街（霓虹燈管旁）**

### 送行

玩家自己操控開到小麥家門口的信箱時播放（自動巡遊經過不算，這一步要玩家自己走過去）：

```
> 抵達：小麥 收
> 收件人狀態：已註銷（2085-03-21）
> 訂單狀態：無法送達
```

畫面停住。音樂和環境音全部淡出，只剩風聲。

接著出現一個按鈕，只有一個選項，不給玩家選擇：

```
[ 播放音訊檔 R11 ]
```

按下後，機器人轉向屋子，把 23:38 那段錄音播出來：閘門「嗶」一聲，他喘著氣喊「小麥？……小麥！」，接著是關門提示音、列車開走。錄音結束時，音樂盒剛好響起〈紅樓之夜〉，就這樣一直放下去。

```
> 投遞：信件 ×1
> 訂單狀態：已送達 ✓
> DLV-06：感謝您的耐心等候。
```

信落進信箱。停一拍之後：

```
> 清除音訊緩衝區？
[ 是 ]　　[ 否 ]
```

- **是**：14 段錄音同時很輕地響起，重疊在一起：警報、雨、救護車、鏟子、廣播、滑板、腳步、閘門、喊名字的聲音……然後一段一段往上淡出、消失。時間線上的錄音波形，一個接一個變成光點飄走。這就是我們的「宇宙葬」：把這座城的聲音送走。之後時間線上只剩遺物，錄音不能再重聽。
- **否**：什麼都不發生。錄音留在時間線上，還能重聽。

兩個選擇都不影響後面的劇情，只是送別的方式不同。

## 遺願（不是必做）

有幾段錄音裡，有人留下一件沒做完的小事。遊戲不會提示，也不會列成任務，只有聽過那段錄音、記得那句話的玩家才會去做。

做完不給獎勵，只會跳出一行：

```
> 已送達
```

| 錄音裡的那句話 | 怎麼完成 | 完成時發生什麼 |
|---|---|---|
| R1「走啦，電影要開始了。」 | 帶著電影票根，停在日昇戲院門口 | 戲院門口的燈閃一下 |
| R4「等清完，想再聽一次那首歌。」 | 帶著卡帶，停在紅樓前 | 機器人的喇叭放起〈紅樓之夜〉，在空城裡放完一整首；附近的鴿子不會被驚動 |
| R8「最後一圈！」 | 沿著紅樓廣場繞一圈 | 繞完的那一刻，滑板輪子的聲音很淡地滾過去一次 |
| R6 阿忠「山上見！」 | 帶著麵線碗，停在草原村的麵線攤前 | 攤子上的鍋子冒出一縷蒸氣 |

戲院燈、蒸氣這種「有東西回應」的時刻全劇只有這四個，而且都很小，讓玩家自己去猜那是不是巧合。

## 同伴：一號顧客

日常裡「問候顧客」時，如果對象是土狗，那隻狗就不會走開，之後一直跟著機器人。第一隻問候的如果是貓，那就等到第一次問候土狗時才發生。

```
> 偵測到顧客（四足）
> 您好！今天想吃點什麼？
> ……
> 顧客未離開
> 登錄為常客：一號顧客
```

- 牠一路跟著，跟丟了會自己追上來。前往草原村時也會一起去。
- 機器人偶爾會對牠報告系統訊息，口氣跟平常一樣，像是 `電量 64%。今天天氣很好。`、`前方路線受阻。我們繞路。`，或是錄音結束後的 `……你也聽到了嗎？`。
- 牠不會說話，但會對錄音有反應：錄音響起時耳朵豎起來，往聲音的方向看，R3 救護車經過時還會跟著吠。這是唯一證明「聲音真的在那裡」的東西，只是牠是狗，沒辦法作證。
- 送行時，牠在信箱旁邊坐下，一直等到音樂盒停下來。

## 時間線長什麼樣

時間線只負責排順序，不畫連線，也不加任何註解。

```
2049 ── 2050 ── 2051 ── 2052 ──── 2053 ──── 2054/4/28 ── 2054/4/30 ▸
 R1      珍奶    黑膠    R2 R3 R4   R5 球鞋    麵線碗        （點開展開）
 票根                    霓虹 卡帶

2054/4/30（以分鐘為單位）
22:50   23:05  23:12  23:20  23:31  23:33  23:38  23:41  23:47  23:52
手機     R6     R7    R8     R9     R10    R11    R12    R13    R14
                      滑板                  悠悠卡
```

- 已取得的節點：遺物顯示小圖示，錄音顯示波形，點了可以重聽或看卡片。
- 未取得的節點：最後一夜顯示 `??:??`，之前的年份顯示 `????`，再加上區域名稱，例如「漢中街附近」。
- 最後一夜那一排要等第二幕開始才出現；在那之前已經撿到的那晚遺物，會先單獨顯示在那一排。
- 有明確時間的遺物（懷錶 23:40）也掛上時間線，玩家自己會發現它卡在 R11 和 R12 中間。
- 沒有日期的草原遺物，放在時間線最右邊的「之後」區。

## 已決定

1. **人物名字**：阿凱、阿禾、聲聲唱片、一號顧客照用。
2. **推進門檻**：第一幕 5 段錄音全部收齊才進第二幕。雷達會對準還沒聽的錄音點，不會卡關。
3. **清除緩衝區**：保留代價，選「是」之後錄音不能再重聽，字幕還留在時間線上。
4. **人聲**：錄音裡的人只用字幕。廣播和人群用含糊的合成雜訊質感，不是真的說話。
5. **機器人語音**：機器人自己的話（「您好！今天想吃點什麼？」「謝謝雨。」「感謝您的耐心等候。」「收到。」等）用瀏覽器的語音合成念出來，音調壓低。混音器裡的「機器人語音」可以調小或關掉。
