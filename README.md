# Meadow Bot

斜俯視角的微縮療癒場景：小外送機器人在兩個場景裡漫遊，追尋一筆三十一年沒送到的訂單。three.js + Vite + TypeScript（strict），所有模型都是程式生成，音效全部用 Web Audio 即時合成。

- **草原**（`?scene=meadow`）：紅磚牆、石板廣場與花草間的鄉村，也是故事裡居民遷去的山上聚落「草原村」。
- **廢土西門町**（預設場景，`?scene=ximending`）：依 OpenStreetMap 真實街道與建物輪廓重建的西門町（紅樓到 6 號出口一帶），數十年無人之後已長成草原：柏油龜裂、大片消失，鋪面只剩石磚碎片，多數樓只剩階梯狀斷牆和騎樓柱，6 號出口外的彩虹斑馬線（依 OSM 標註的位置）褪色但還認得出來。參考街景做出幾處認得出來的地方：6 號出口廣場、新世界大樓的圓筒玻璃塔與漢中街的黃色燈桿、武昌街電影街的手繪電影看板與光環燈柱、峨眉街的青綠光環燈桿與麵線攤（招牌文字皆已改寫）。沒有人，但街上住著流浪貓、台灣土狗和鴿群：貓在機器人靠近時會盯著看、太近就逃開，土狗會跑過來吠一聲跟著走一段，鴿群被驚動就整群飛起換個地方降落；聲音也換成風穿過空樓的呼嘯、招牌吱嘎、鐵捲門震動和烏鴉。從捷運西門站 6 號出口出發，巡遊漢中街、峨眉街、武昌街與成都路。

```bash
npm install
npm run dev
```

`npm run typecheck` 跑型別檢查（`src` 與 `scripts`），`npm run build` 會先型別檢查再打包。


## 操作

- 進入遊戲先到主選單（背景是上次玩到的場景）：「繼續」接著存檔玩，「新遊戲」會先確認，再清除進度（遺物、錄音、故事、同伴；語言與音量設定保留）從西門町重新開始。切換場景或語言不會再經過主選單
- WASD / 方向鍵：移動（依目前視角）
- 拖曳畫面 / Q、E：轉視角與俯仰；滾輪：縮放；雙擊：回到預設視角
- 點地面或左上角地圖：前往該位置
- R：下雨 / 放晴（不按也會晴雨交替）
- B：紀錄（或點畫面上方的雷達）
- M：開關地圖（廢土西門町）
- 閒置 4 秒：自動巡遊
- 右下角：切換場景，以及 ⚙️ 設定（主選單的「設定」也是同一個面板）：語言（中文 / English，預設跟隨瀏覽器語言）、聲音開關（瀏覽器需要先點一下才會出聲）、總音量與音樂、環境、天氣、動物、機器人、機器人語音、故事（錄音與歌）、提示音各自的音量；設定都記在這個瀏覽器

## 故事

台北盆地本來就是一片會積水的低地（1694 年曾積成「康熙台北湖」）。二〇四〇年代起，海平面上升讓河堤越來越吃緊，警報一年響好幾次；2052 年白鷺颱風讓淡水河漫過河堤，西門町泡在一樓半深的水裡三個星期。2053 年政府公布「綠洲遷居計畫」，2054 年 4 月 30 日 23:40 最後一班捷運開走，城市慢慢被淤泥上長出的草原吞沒。

外送機器人 DLV-06 在 2085 年重新開機。完整劇本在 [storyboard/script.md](storyboard/script.md)，玩起來是這樣：

1. **日常**：醒來後照著三十一年前的「今日排程」過一天：曬太陽充電、跟貓狗打招呼、衝散鴿群、在彩虹斑馬線前等一個不會亮的燈。沒有目標，自動巡遊也會慢慢做完。第一隻被問候、沒有走開的土狗會變成同伴「一號顧客」，之後一路跟著，草原村也一起去。
2. **錄音**：排程跑完後，冒出一筆沒結案的訂單，資料損毀。機器人改讀音訊緩衝區：經過某些地點時，周圍的聲音會壓低，響起三十一年前的聲音（警報、颱風夜的水聲、救護車、有人在跑、捷運開走），但畫面上什麼都沒有，只有機器人的轉錄字幕。整體混音是單聲道，只有錄音是立體聲，會依畫面方向在左右展開。第一幕是 2049–2053 年的大水，第二幕是最後一夜 23:05–23:47，最後一段在它醒來的地方。
3. **紀錄**：找到的遺物和聽到的錄音，照遇到的先後記下來（B 或點雷達），不會照時間排。每張卡片寫著自己的日期，排回那一晚的先後是玩家自己的事；卡片和字幕只寫事實。
4. **六號出口**：訂單還原後，送到六號出口，打開信，查到收件人的新地址，前往草原村。
5. **草原村**：在小麥家門口送行。之後可以選擇清除音訊緩衝區；找到她留下的 31 封信，會收到一筆新訂單。

另外有幾件錄音裡沒做完的小事，遊戲不提示，聽過、記得那句話的人才會去做。

場景裡也留著線索：每棟樓一樓半高的水漬線與底下乾掉的淤泥、遷居公告與最後一班捷運的告示、麵線攤和戲院的歇業告示、疏散指標，以及店門口和捷運出口的沙包。故事進度存在這個瀏覽器裡。

## 拾荒

兩個場景都藏著舊時代的遺物（西門町 10 件、草原 5 件），各自擺在跟它回憶有關的地標旁：麵線碗在麵線攤、電影票根在電影街、悠悠卡在六號出口……畫面上方的雷達會隨著離最近的遺物越近，訊號格越滿、嗶聲越急；靠近到幾公尺內，遺物會閃光。自己操控機器人開過去就會撿起來（自動巡遊時不會撿），跳出一張回憶小卡。紀錄裡收集到的會顯示卡片內容，還沒找到的顯示剪影和線索。主線開始後，雷達也會接收還沒聽過的錄音點。收集進度存在這個瀏覽器裡。

## 天氣

晴天與陣雨輪流出現。下雨時天色轉灰、霧氣變近，雨絲隨鏡頭落下，草和樹被風吹得更大；所有表面慢慢濕透變深變亮、牆面有水流下，地上低處積出水窪並被雨滴打出漣漪，倒映灰白的天空；雨停後再慢慢變乾。大雨時偶爾有閃電和遠雷。

## 省電

畫面最多每秒 30 幀；視窗不在前景（切到別的 App 或視窗）時完全停止渲染，切回來從原處繼續。

## 地圖資料

西門町的街道、建物輪廓與樓層數、捷運出口位置來自 OpenStreetMap，存成 `src/data/ximending.json`，執行時不需連網。重新抓取：

```bash
node scripts/fetch-ximending.ts
```

地圖資料 © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)，以 ODbL 授權。遊戲裡的標示在廢土西門町的設定面板最下方（依 OSM 標示指引，遊戲可放在選單或製作名單）。

## 結構

| 檔案 | 內容 |
|---|---|
| `src/main.ts` | 渲染器、依 `?scene=` 或上次玩的場景載入、主選單、鏡頭跟拍、場景切換、30 fps 上限與背景暫停 |
| `src/world.ts` | 場景與主程式之間的型別約定：場景定義（外觀、起點、巡遊路線、build）與 build 交回的 world（導航、地標、遺物與錄音位置、動物、小地圖） |
| `src/osm.ts` | `src/data/ximending.json` 的資料型別，抓取腳本與城市場景共用 |
| `src/types/n8ao.d.ts` | n8ao 沒有附型別，這裡宣告專案用到的部分 |
| `src/save.ts` |
 存檔：判斷有沒有進度、清除進度（保留語言與音量）、記住上次的場景、標記遊戲自己重新載入（不經過主選單） |
| `src/settings.ts` | 設定面板：語言、聲音開關與各聲道音量，遊戲中與主選單都能打開 |
| `src/menu.ts` | 主選單：在場景上方的「繼續 / 新遊戲」，新遊戲有存檔時先確認 |
| `src/meadow.ts` | 草原場景：佈景、草與花的分布規則、巡遊路線、光線 |
| `src/meadow-terrain.ts` | 草原地形高度、草地 / 泥土路 / 乾草區 / 廣場分區 |
| `src/ximending.ts` | 廢土西門町場景：把 OSM 資料轉成建物、補齊空地店屋、倒下的高樓、捷運出口、電視牆、廢車、植被與揚塵 |
| `src/city-ground.ts` | 依真實道路繪製的地面：shader 逐像素畫出龜裂的柏油板塊、殘存的石磚碎片與泥土，CPU 端同一套規則決定草長在哪；褪色的彩虹斑馬線 |
| `src/city.ts` | 依 OSM 輪廓長出的樓（臨街騎樓）、騎樓店屋、沿樓層階梯斷裂的空殼 / 倒塌 / 傾斜殘樓、瓦礫與鋼筋、直式招牌、橫倒的高樓、依區塊合併的靜態網格 |
| `src/city-props.ts` | 廢車、路燈、紅樓的拱窗與八角屋頂、台北捷運風格的出口、圓盤燈、新世界大樓圓筒塔、黃色 L 型燈桿、換字的大型廣告與樓頂看板、電影院門面、光環燈柱、麵線攤、碎裂的電視牆、遷居公告欄、疏散指標、沙包 |
| `src/minimap.ts` | 左上角遊戲風格小地圖：米白圓角框、緞帶標題、指北針，場景提供的平面圖（卡通道路，加上機器人走不到的地方）畫一次，每幀疊上帶呼吸光環的機器人標記；點地圖讓機器人前往 |
| `src/walkmap.ts` | 導航格子：由場景自己的碰撞體算出機器人走得到的範圍（0.5 公尺格子、加上機器人半徑、取最大連通區），A* 尋路並拉直成直線段；巡遊與點擊前往都照它走，小地圖也據此畫出不能走的地方 |
| `src/orbit.ts` | 繞著機器人的鏡頭：拖曳轉向與俯仰、滾輪縮放、Q / E 旋轉，沒拖動的點擊才當成前往 |
| `src/weather.ts` | 晴雨循環、跟著鏡頭的雨絲、讓所有材質濕透的 shader（變暗變亮、牆面水流、地面水窪與漣漪）、陰天環境貼圖、閃電 |
| `src/story.ts` | 故事分幕：開機、訂單浮現、兩段幕間、訂單還原、六號出口的信、草原村的送行（播放 R11、清除緩衝區的選擇）與新訂單；目前任務的目的地與進度存檔 |
| `src/echoes.ts` | 機器人的 14 段錄音：時間、幕、觸發範圍、轉錄字幕的時間點，經過錄音點時播放並存檔 |
| `src/echo-audio.ts` | 錄音的合成聲音：警報、暴雨、救護車（都卜勒）、鏟子、廣播、鐵捲門、滑板、腳步、閘門、列車、停電，全部過一層舊錄音的音色 |
| `src/song.ts` | 〈紅樓之夜〉的旋律（原創），收音機、機器人喇叭和音樂盒都用它 |
| `src/routine.ts` | 日常：今日排程的七個項目、完成判定、主線前的觸發；之後留下的習慣（問候動物、在斑馬線前等燈） |
| `src/companion.ts` | 同伴「一號顧客」：認養、跨場景跟隨、聽到錄音時的反應、偶爾的系統訊息 |
| `src/wishes.ts` | 錄音裡沒做完的四件小事：條件判定與完成時的小回應（戲院的燈、喇叭放歌、滑板聲、麵攤的蒸氣） |
| `src/syslog.ts` | 雷達下方一行一行的機器人系統訊息 |
| `src/voice.ts` | 機器人的語音：瀏覽器內建的語音合成，音調壓低、稍慢；只有機器人說話，錄音裡的人只有字幕 |
| `src/relics.ts` | 遺物清單：卡片上的日期、名稱、卡片內容、地點線索，以及各自的小模型 |
| `src/scavenge.ts` | 拾荒：在場景擺出遺物、靠近時閃光、撿起的飛入動畫、雷達訊號、收集進度存檔 |
| `src/notebook.ts` | 紀錄介面：雷達訊號列、撿到時的小卡，以及照遇到的先後列出的遺物與錄音（縮圖由另一個小渲染器一次畫好），可重聽錄音 |
| `src/cutaway.ts` | 鏡頭與機器人之間的建物以抖動透明挖空，避免擋住機器人 |
| `src/terrain.ts` | 共用的亂數、雜訊，與目前場景的地形高度 |
| `src/vegetation.ts` | 草叢（InstancedMesh + 風擺 shader）、小花、蘆葦、魯冰花、常春藤，以及由上千片葉枝組成的樹與灌木 |
| `src/bricks.ts` | 圓角磚牆（沿曲線掃掠 + 程式磚紋與青苔 shader）、磚柱、整塊拱形涵洞、倒塌牆塊 |
| `src/props.ts` | 草原的拱門磚房、石板廣場、落葉碎石、木桶、電線桿、柵欄、鐵門、帆布攤位、燈串、小木屋等 |
| `src/animals.ts` | 會吃草的牛、四處嗅聞的狐狸、會啄地亂走的雞、散步的村民（只出現在草原） |
| `src/strays.ts` | 廢土西門町的動物：流浪貓、台灣土狗、鴿群，沿導航格子在少草的地面活動，並對機器人做出反應 |
| `src/robot.ts` | 六輪外送機器人模型、操控、沿規劃路線巡遊與前往點擊處（卡住時重新規劃） |
| `src/collision.ts` | 2D 膠囊碰撞、植被避開障礙物用的佔用格 |
| `src/post.ts` | AO（n8ao）→ Bloom、移軸景深、ACES 調色（下雨時轉灰）→ SMAA |
| `src/weathering.ts` | 共用的做舊 shader：髒污、牆腳泥垢、積灰、褪色、木紋、鏽斑、雨痕、大水留下的水漬線與淤泥，以及凹凸起伏 |
| `src/graffiti.ts` | Canvas 即時繪製的噴漆塗鴉貼花：滴痕簽名（tag）與粗描邊泡泡字（piece） |
| `src/audio.ts` | 風聲、樹葉、鳥叫、動物叫聲（牛、雞、貓、狗、鴿子、拍翅）、馬達聲、音樂盒旋律；城市場景另有空樓風嘯、招牌吱嘎、鐵捲門與烏鴉，旋律改小調 |
| `scripts/fetch-ximending.ts` | 從 Overpass API 抓取西門町 OSM 資料並轉成本地公尺座標 |
